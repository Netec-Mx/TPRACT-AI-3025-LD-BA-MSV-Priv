# Taller práctico de productividad con Microsoft Copilot y agentes de IA

## Plataforma de laboratorios

Taller de aplicación de **Microsoft Copilot Chat Básico** y agentes preconstruidos previamente habilitados por el cliente para resolver situaciones habituales de Banco Agrícola: atención a productores, comunicaciones, propuestas, reuniones y aprendizaje interno. Se utilizan exclusivamente **datos y escenarios ficticios**; las respuestas de IA deben contrastarse con el material proporcionado.

**Duración total:** 2 horas (120 minutos). **Distribución:** 100 % práctica. **Público:** colaboradores de atención, operaciones, áreas comerciales, administrativas, recursos humanos y equipos de apoyo.

Antes de comenzar, consultar la **[Setup Guide general](SETUP_GUIDE.md)** para validar el acceso a Copilot Chat Básico y los diez agentes. Una plantilla de Agent Builder no equivale a un agente ya disponible para usar.

## Lista de laboratorios

### Capítulo 1. Práctica: instrucciones efectivas para situaciones bancarias

#### [Práctica 1. Instrucciones efectivas para situaciones bancarias](Capitulo01/README.md)

- **Descripción:** formular un prompt estructurado y revisar dos respuestas para orientar a una persona productora sobre los pasos generales de una posible solicitud de crédito, sin inventar requisitos ni condiciones.
- **Duración:** 20 minutos (8 + 8 + 4).

### Capítulo 2. Práctica: comunicaciones claras para clientes agrícolas

#### [Práctica 2. Comunicaciones claras para clientes agrícolas](Capitulo02/README.md)

- **Descripción:** solicitar dos elementos pendientes en un correo ficticio, convertirlo en un recordatorio y traducirlo al inglés revisando significado y tono.
- **Duración:** 25 minutos (10 + 7 + 8).

### Capítulo 3. Práctica: preparación de propuestas y respuestas comerciales

#### [Práctica 3. Preparación de propuestas y respuestas comerciales](Capitulo03/README.md)

- **Descripción:** crear un borrador de propuesta y preguntas frecuentes a partir de una ficha de **condiciones ficticias**, identificar datos sin respaldo y preparar una lista de puntos por validar.
- **Duración:** 25 minutos (10 + 8 + 7).

### Capítulo 4. Práctica: acuerdos de reuniones y seguimiento

#### [Práctica 4. Acuerdos de reuniones y seguimiento](Capitulo04/README.md)

- **Descripción:** extraer acuerdos y responsables de una minuta simulada y convertirlos en actividades con prioridad y estado inicial, sin inventar decisiones.
- **Duración:** 25 minutos (10 + 10 + 5).

### Capítulo 5. Práctica: aprendizaje y evaluación interna

#### [Práctica 5. Aprendizaje y evaluación interna](Capitulo05/README.md)

- **Descripción:** crear una guía de inducción y cinco preguntas de comprobación sustentadas en un documento de aprendizaje ficticio.
- **Duración:** 25 minutos (10 + 10 + 5).

**Total: 20 + 25 + 25 + 25 + 25 = 120 minutos.**

# TALLER PRÁCTICO DE PRODUCTIVIDAD CON MICROSOFT COPILOT Y AGENTES DE IA

Taller de aplicación de Microsoft Copilot Chat Básico y agentes preconstruidos para resolver situaciones cotidianas de Banco Agrícola: comunicación con clientes, propuestas, reuniones y capacitación. Adaptación práctica del curso AI-3025 Work smarter with AI, centrada en la exploración de Copilot Chat Básico, los prompts efectivos y la generación y revisión de contenido.

## Lista de laboratorios

### Capítulo 1

- [Práctica: Instrucciones efectivas para situaciones bancarias](Capitulo01/README.md#práctica-instrucciones-efectivas-para-situaciones-bancarias)
  - Descripción: Caso: un ejecutivo debe explicar a un productor agrícola los pasos generales de una solicitud de crédito sin inventar requisitos ni condiciones. 1.1 Explorar Asistente de indicaciones y formular un prompt con rol, contexto, objetivo, formato y restricciones (8 minutos). 1.2 Usar Asistente de escritura para crear una primera respuesta y mejorarla con una segunda instrucción (8 minutos). 1.3 Comparar las dos respuestas e identificar información que exige verificación institucional (4 minutos). Entregable: prompt mejorado y respuesta revisada al cliente.
  - Duración estimada: 20 min
  - [Ver capítulo completo](Capitulo01/README.md)

### Capítulo 2

- [Práctica: Comunicaciones claras para clientes agrícolas](Capitulo02/README.md#práctica-comunicaciones-claras-para-clientes-agrícolas)
  - Descripción: Caso: comunicar una solicitud de documentos faltantes y adaptar el mensaje para una persona que prefiere otro idioma. 2.1 Elaborar un correo claro y cordial con Diseñador de comunicaciones corporativas (10 minutos). 2.2 Convertir el mensaje en un recordatorio breve usando Asistente de escritura (7 minutos). 2.3 Traducir el mensaje con Traductor de texto; revisar sentido, tono y terminología (8 minutos). Entregable: correo, recordatorio y traducción validados.
  - Duración estimada: 25 min
  - [Ver capítulo completo](Capitulo02/README.md)

### Capítulo 3

- [Práctica: Preparación de propuestas y respuestas comerciales](Capitulo03/README.md#práctica-preparación-de-propuestas-y-respuestas-comerciales)
  - Descripción: Caso: una asociación de productores solicita información sobre un servicio bancario empresarial; los participantes trabajarán únicamente con una ficha ficticia de condiciones. 3.1 Estructurar una respuesta con Generador de solicitudes de propuesta (10 minutos). 3.2 Consultar al Asistente de información disponible para organizar preguntas frecuentes, utilizando datos ficticios proporcionados en el prompt y sin presumir acceso a sistemas bancarios (8 minutos). 3.3 Identificar afirmaciones sin respaldo y ajustar el borrador sin inventar tasas, requisitos ni compromisos (7 minutos). Entregable: borrador de propuesta y lista de puntos por validar.
  - Duración estimada: 25 min
  - [Ver capítulo completo](Capitulo03/README.md)

### Capítulo 4

- [Práctica: Acuerdos de reuniones y seguimiento](Capitulo04/README.md#práctica-acuerdos-de-reuniones-y-seguimiento)
  - Descripción: Caso: reunión simulada entre las áreas comercial, riesgos y operaciones para coordinar una campaña de atención a productores. 4.1 Usar Asesor de reuniones para convertir una minuta ficticia en acuerdos y responsables (10 minutos). 4.2 Emplear Asistente de scrum para transformar los acuerdos en actividades, prioridades y estado inicial (10 minutos). 4.3 Revisar que las tareas correspondan a la minuta y no incluyan decisiones inventadas (5 minutos). Entregable: minuta estructurada y tablero/lista de tareas.
  - Duración estimada: 25 min
  - [Ver capítulo completo](Capitulo04/README.md)

### Capítulo 5

- [Práctica: Aprendizaje y evaluación interna](Capitulo05/README.md#práctica-aprendizaje-y-evaluación-interna)
  - Descripción: Caso: inducción de nuevo personal sobre buenas prácticas para atender consultas de clientes rurales usando una guía institucional ficticia. 5.1 Crear una guía breve de aprendizaje con Asistente de aprendizaje (10 minutos). 5.2 Elaborar cinco preguntas de comprobación con Tutor de cuestionarios (10 minutos). 5.3 Resolver y ajustar las preguntas, comprobando respuestas contra el material de entrada (5 minutos). Entregable: guía de inducción y cuestionario de cinco preguntas con respuestas.
  - Duración estimada: 25 min
  - [Ver capítulo completo](Capitulo05/README.md)
